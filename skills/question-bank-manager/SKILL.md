# 试题入库管理

收到试题后，自动完成以下流程：

---

## 工作流程

### Step 1 — 判断题型

根据试题形式判断：

| 特征 | 题型 |
|------|------|
| 4个选项（①②③④）、有设问、选正确答案 | **选择题** |
| 有材料/情景 + 设问 + 需要文字作答、有分值标注 | **材料题** |

### Step 2 — 分析知识点，匹配教材位置

逐题阅读试题内容，提取考查的核心知识点，然后读取对应的教材框架文件进行匹配：

| 教材 | 框架文件 |
|------|---------|
| 七年级上册 | `~/.claude/projects/-Users-liwvken/memory/textbook-7a.md` |
| 七年级下册 | `~/.claude/projects/-Users-liwvken/memory/textbook-7b.md` |
| 八年级上册 | `~/.claude/projects/-Users-liwvken/memory/textbook-8a.md` |
| 八年级下册 | `~/.claude/projects/-Users-liwvken/memory/textbook-8b.md` |

匹配方法：
1. 从试题中提取关键知识点（概念、原理、制度名称等）
2. 读取对应学段的教材框架文件
3. 定位到最匹配的课次

### Step 3 — 确认入库位置

向用户展示分析结果，格式如下：

```
## 试题入库分析

**题型**：选择题
**知识点**：宪法是国家根本法
**对应位置**：八年级下册 → 第一课 治国安邦的总章程
**入库路径**：question-bank/选择题/八年级下册/第一课-治国安邦的总章程/

确认存入？(y/n)
```

### Step 4 — 编号与存储

用户确认后：

1. 检查目标目录下已有文件数量，自动编号（如已有 000-003，则新文件为 004）
2. 文件命名：`{题型缩写}-{三位编号}.md`
   - 选择题：`xz-001.md`
   - 材料题：`cl-001.md`
3. 文件内容格式如下

**选择题文件模板：**
```markdown
---
type: 选择题
knowledge-point: (核心知识点，5-10字)
grade: (七年级上/下 或 八年级上/下)
lesson: (第X课 课名)
core-literacy: (政治认同/道德修养/法治观念/健全人格/责任意识)
difficulty: (易/中/难)
date-added: (入库日期 YYYY-MM-DD)
---

## 题目

**题干**：(完整题干)

**选项**：
① ……
② ……
③ ……
④ ……

**答案**：①/②/③/④

**解析**：(详细解析：正确选项为什么对，错误选项为什么错)
```

**材料题文件模板：**
```markdown
---
type: 材料题
knowledge-point: (核心知识点，5-10字)
grade: (七年级上/下 或 八年级上/下)
lesson: (第X课 课名)
core-literacy: (政治认同/道德修养/法治观念/健全人格/责任意识)
difficulty: (易/中/难)
date-added: (入库日期 YYYY-MM-DD)
---

## 题目

**材料**：(情景材料全文)

**设问**：(设问全文，含分值)

**参考答案**：(完整答案)

**评分标准**：(如有)
```

### Step 5 — 完成确认

输出入库结果：

```
✅ 已存入：question-bank/选择题/八年级下册/第一课-治国安邦的总章程/xz-001.md
```

## 批量入库

用户一次发多道题时，逐道分析后在一次确认中展示全部：

```
## 批量入库分析

| 序号 | 题型 | 知识点 | 对应教材 | 入库路径 |
|------|------|--------|---------|---------|
| 1 | 选择题 | 宪法地位 | 八下·第一课 | 选择题/八下/第一课/xz-001.md |
| 2 | 材料题 | 权利义务 | 八下·第三课 | 材料题/八下/第三课/cl-001.md |
| 3 | 选择题 | 国家安全 | 八上·第十二课 | 选择题/八上/第十二课/xz-001.md |

确认全部存入？(y/n)
```

---

## 注意事项

1. **知识点匹配优先精确**：不确定属于哪一课时，宁可向用户提问确认，不要硬塞。
2. **跨课知识点选最核心的**：一道题可能涉及多个知识点，选最核心、最直接考查的那个作为主归类。
3. **教材框架是唯一参照**：匹配知识点时必须以教材框架文件为准，不可凭记忆猜测。
4. **编号自动递增**：每次入库前先检查目标目录已有文件数。
