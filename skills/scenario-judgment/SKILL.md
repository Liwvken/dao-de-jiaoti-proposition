# 情景核心知识判断题

命题前，必须先读取 `~/.claude/projects/-Users-liwvken/memory/proposition-general-requirements.md` 获取完整的命题总要求（命题依据、目标、原则、规划、学业质量、逻辑规范等）。

---

## 题型定位

### 与传统判断题的区别

| | 传统判断题 | 情景核心知识判断题 |
|------|-----------|-----------------|
| **有无情景** | 无情景，孤立判断 | 有真实情景包裹 |
| **考查方式** | 机械判断对错 | 在情境中识别知识正误 |
| **素养指向** | 知识记忆 | 知识理解与运用 |
| **教学价值** | 低（易猜答案） | 高（帮助提升客观题正确率） |

### 基本原则

**无情景不命题**——每道判断题必须嵌套在一个真实情景中。学生在阅读情景后，对其中涉及的核心知识表述进行判断和改错。

---

## 自动化命制流程

按以下步骤依次执行，不得跳过。

---

### Step 1 — 确认需求

向用户确认以下信息（如用户已明确给出该项则跳过）：

1. **年级/学段**：七年级 / 八年级 / 九年级 / 中考
2. **知识板块**（六大板块可选一或多选）
3. **具体考点或主题**
4. **每组数量**：一组通常3-5道判断小题
5. **难度**：基础版 / 提高版
6. **考试性质**：课堂练习 / 单元检测 / 会考 / 中考模拟

汇总输出：
```
## 命题规划
- 年级：八年级
- 知识板块：法治教育
- 考点：公民的权利与义务
- 数量：一组4道判断小题
- 难度：基础版
- 考试性质：单元检测
```

---

### Step 2 — 情景选择 ⚠️ 必须先询问用户

**必须向用户提问：**
> "你手头是否有现成的素材或案例？如果有请直接提供，如果没有我将在权威网站搜索近6个月的相关情景素材。"

**两种情况：**

**【情况A】用户有素材** → AI 改编为适合嵌入知识判断点的情景（100-200字）。

**【情况B】用户无素材** → 联网搜索（来源清单同客观题技能）。呈现 2-3 个候选情景，用户选定后改编。

**情景改编要求：**
- 长度：100-200字，适合在一段情景中嵌入3-5个知识判断点
- 情景类型可多样化：
  - 校园生活场景（班会讨论、课堂辩论、社团活动）
  - 社会新闻事件（某一具体案例/现象）
  - 政策文件片段（法律条文/政府工作报告节选）
  - 人物事迹（某模范人物的言行）
  - 数据/图表（配合文字说明）
- 情景须自然、可读，知识点嵌入不显突兀
- 正向价值导向

---

### Step 3 — 知识点嵌入设计

在情景中确定3-5个核心知识判断点，设计为判断小题。

#### 3.1 错误类型全覆盖

确保每组判断题覆盖至少2-3种错误类型：

| 错误类型 | 标注 | 说明 | 示例 |
|---------|------|------|------|
| **知识性错误** | 【知识性】 | 概念混淆、主体错位、关系错乱 | "居委会是基层国家机关"（居委会≠国家机关） |
| **逻辑性错误** | 【逻辑性】 | 绝对化、以偏概全、因果颠倒、无关推断 | "只要守法就一定能成功"（充分条件不当） |
| **价值性错误** | 【价值性】 | 功利取向、价值观偏颇 | "帮助他人是为了获得表扬" |

#### 3.2 正误混合

一组判断小题中，应包含：
- 正确表述（约1/3，避免学生形成"全部是错"的答题惯性）
- 错误表述（约2/3，覆盖不同错误类型）

#### 3.3 判断点设计要求

- 每道判断小题是一句**完整、明确的核心知识表述**
- 表述与情景内容直接相关（学生需要回到情景中判断）
- 错误点明确、有教育意义（不是文字游戏）
- 正确答案唯一、无争议
- 错误表述有明确的改错方向

---

### Step 4 — 题干与判断任务设计

#### 4.1 题干结构

```
【情景材料】（100-200字）
（完整的情景描述）

【判断任务】
阅读上述情景，判断以下关于核心知识的表述是否正确（正确的打"✓"，错误的打"✗"），并对错误的表述写出正确说法。

（1）……（表述1）
（2）……（表述2）
（3）……（表述3）
（4）……（表述4）
```

#### 4.2 指令语要求

- 清晰的判断方式（打✓打✗ / 写"正确""错误"）
- 明确的改错要求（"对错误的写出正确说法"）
- 合适的答题空间提示（"在横线处写出正确说法"）

---

### Step 5 — 命题检验（完整审题流程）

逐项检验，全部通过方可输出。

#### 5.1 情景检验
- [ ] 情景是否真实/基于真实事件
- [ ] 情景与知识判断点是否自然关联（非生硬插入）
- [ ] 情景信息是否足够支撑判断（不需要额外知识才能理解情景）
- [ ] 情景字数是否在100-200字之间

#### 5.2 知识性检验
- [ ] 每道判断小题涉及的知识点表述准确
- [ ] 错误表述的错误点明确、无疑义
- [ ] 正确表述的知识确实正确
- [ ] 正确答案唯一可确定

#### 5.3 逻辑性检验
- [ ] 错误表述的逻辑错误类型清晰
- [ ] 不存在模糊地带（半对半错、争议性表述）
- [ ] 改错方向明确

#### 5.4 教育性检验
- [ ] 每道错误题有明确的教学价值（纠正一个典型认知误区）
- [ ] 错误类型标注准确
- [ ] 正误混合比例合理（≈1/3正确 + ≈2/3错误）

#### 5.5 政治性检验
- [ ] 情景素材权威可查
- [ ] 价值导向正确
- [ ] 无敏感争议内容

## 注意事项

1. **情景是灵魂**：不同于传统判断题的孤立判断，情景使学生必须在具体语境中识别知识正误——这正是客观题解题的核心能力。
2. **错误要有营养**：每个错误表述应指向一个典型的学生认知误区，学生改错的过程就是纠正误区、巩固知识的过程。
3. **不要全部是错**：至少设置1道正确表述，避免学生形成"凡是判断一定是错的"惯性。
4. **改错方向要明确**：学生不会改的具体错误=失败的判断题。每个错误表述都有清晰正确的改法。
5. **与客观题技能协同**：判断题排除的错误类型（绝对化、主体错位、概念偷换、无关项、功利表述），可以直接迁移到客观题的干扰项识别能力。
