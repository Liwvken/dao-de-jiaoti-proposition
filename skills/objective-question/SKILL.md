# 客观题命制（选择题）

命题前，必须先读取 `~/.claude/projects/-Users-liwvken/memory/proposition-general-requirements.md` 获取完整的命题总要求（命题依据、目标、原则、规划、学业质量、逻辑规范等）。

## 自动化命制流程

按以下步骤依次执行，不得跳过。每步完成后向用户确认或展示结果，再进行下一步。

---

### Step 1 — 确认需求

向用户确认以下信息（如用户已明确给出该项则跳过）：

1. **年级/学段**：七年级 / 八年级 / 九年级 / 中考
2. **知识板块**（六大板块可选一或多选）：
   - 个人成长 | 道德品质 | 法治教育 | 国家制度 | 国情发展 | 国际视野
3. **具体考点**（用户可指定，也可由AI从板块中选定后请用户确认）
4. **数量与难度**：几道题？基础版 / 提高版？
5. **考试性质**：随堂练习 / 期末考试 / 会考 / 中考模拟

汇总输出：
```
## 命题规划
- 年级：九年级
- 知识板块：法治教育
- 考点：宪法的地位与效力
- 数量：3道 ｜ 难度：基础版
- 考试性质：中考模拟
```

---

### Step 2 — 确定考点与双向细目表

根据确认的需求，为每道题输出双向细目表：

| 题号 | 知识点 | 核心素养 | 学科任务层级 | 难度 |
|------|--------|---------|-------------|------|
| 1 | …… | …… | 辨识与判断/阐释与论证/探究与建构 | 易/中/难 |

学科任务层级说明：
- **辨识与判断**：识别概念、判断正误——适合基础题
- **阐释与论证**：解释因果关系、论证观点——适合中档题
- **探究与建构**：多角度分析、提出方案——适合提高题/压轴题

难度分布建议：容易:中等:难题 = 7:2:1

---

### Step 3 — 情景选择 ⚠️ 必须先询问用户

**必须向用户提问：**
> "你手头是否有现成的素材或案例？如果有请直接提供，如果没有我将在权威网站搜索近6个月的相关情景素材。"

**两种情况：**

**【情况A】用户有素材** → AI 精简改写至2-3行（约80-120字），保留核心事实与数据，专业术语用括号加通俗解释。

**【情况B】用户无素材** → 联网搜索。搜索范围限定：
- 人民网、新华网、教育部官网、中国普法网、最高法/最高检官网、央视网、学习强国
- 四川省政府、省教育厅；成都市政府、市教育局
- 中国共产党新闻网、中组部党建平台
- 筛选条件：近6个月，与考点直接关联，正向价值导向，真实权威

呈现 2-3 个候选情景（标注来源和日期），用户选定后精简改写至2-3行。

**精简改写规则：**
- 保留核心事实与数据，删除冗余描述
- 专业术语、政策名词须用通俗语言解释（如"新质生产力"须加括号说明）
- 确保初中生能读懂
- 不改变材料原意和基本价值导向
- 正向价值导向

---

### Step 4 — 题干设计

**规范：**
- **长度**：2-3行，不超过4行（约80-160字）
- **结构**：情景材料 + 设问句，构成完整语义
- **主题**：明确而完整，为正确选项提供足够信息
- **用词**：专有名词和特定名词完整表述，避免不规范省略（如"全国人民代表大会"不简写为"全国人大"首次出现时）
- **政治正确**：符合习近平新时代中国特色社会主义思想

输出题干后标注字数。

---

### Step 5 — 设问设计

**必须使用以下四类设问词之一：**

| 类别 | 关键词 | 适用场景 |
|------|--------|---------|
| 体现类 | 这体现了、这表明、这说明、由此可见 | 从材料归纳结论、现象→本质 |
| 因果类 | 这是因为、这是基于、这有利于 | 分析原因、意义、必要性 |
| 措施类 | 为此、……应该、这启示我们、这要求我们 | 提出行动方案、给建议 |
| 认识类 | 对此认识正确的是 | 综合判断正误 |

**禁止使用：** "下列说法正确的是""你对此的看法是""以下说法错误的是"

**设问要求：** 准确简明，避免歧义；设问和选项连起来能构成一句完整的话。

---

### Step 6 — 选项设计

#### 6.1 形式规范
- **4个选项**，字数尽量一致（四个一致）或两两一致
- 各选项在意义上独立，不重叠不相互排斥
- 各选项之间构成相互干扰关系（这是选择题区别于判断题的关键）
- 选项组合排列：先排①，再排②，最后排③，每个选项使用频率均衡（约两到三次）
- 涉及党、社会主义制度等内容的选项，慎重考虑政治性和导向性

#### 6.2 正确选项
- 对题干核心意思进行准确解读
- 与题干在内容和表述上构成必然的、正确的逻辑关系
- 唯一正确，无争议

#### 6.3 干扰项设计（3个）

从以下类型中选取，每个干扰项须明确标注其类型：

| 干扰类型 | 说明 | 示例 |
|---------|------|------|
| **绝对化** | 以偏概全、过度推断、偷换模态 | "彻底消除""所有公民都会……" |
| **主体错位** | 张冠李戴，混淆不同主体的职权/义务/性质 | 把政府的职能说成党的职能、把政协说成国家机关 |
| **概念偷换** | 近义词替换导致意义变化 | "根本政治制度"→"基本政治制度""监察权"→"检察权" |
| **无关项** | 表述本身正确但与题干内容无逻辑关联 | 题干说环保，选项谈科技创新 |
| **功利表述** | "旨在树立形象""为了追求名利"——价值导向有问题 | 一定错误 |
| **关系错乱** | 因果颠倒、主次倒置 | "国家利益是人民利益的集中体现"（说反了） |

干扰项设计要求：
- 指向典型的学生认知误区
- 尽可能与题干某些部分相关，使迷惑项看起来可能
- 有明确的、可解释的错误点，而非模糊排除

### Step 7 — 命题检验（完整审题流程）

逐项检验，标注结果。全部通过方可输出。不通过的标注问题并修正后重新检验。

#### 7.1 政治性检验
- [ ] 价值导向正确、积极向上
- [ ] 符合习近平新时代中国特色社会主义思想
- [ ] 素材来源权威可查
- [ ] 涉及党政制度、民族宗教的选项不产生负面引导

#### 7.2 科学性检验
- [ ] 知识点表述准确，无知识性错误
- [ ] 概念使用符合统编教材规范
- [ ] 答案唯一正确、确定、无争议
- [ ] 不存在主体错位、概念偷换等硬伤

#### 7.3 逻辑性检验
- [ ] 正确选项与题干有必然的、正确的逻辑关联
- [ ] 每个干扰项有明确、可解释的错误点
- [ ] 无逻辑谬误（绝对化、因果倒置、偷换概念、无关推断）
- [ ] 情境、题干、设问、选项四者逻辑统一
- [ ] 题干与四个选项分别能构成完整语句

#### 7.4 规范性检验
- [ ] 题干2-3行（不超过4行，约80-160字）
- [ ] 专有名词和特定名词完整表述
- [ ] 选项字数相近或两两对齐，排列美观
- [ ] 未使用否定式提问（"以下说法错误的是"等）
- [ ] 未使用"下列说法正确的是"

#### 7.5 公平性检验
- [ ] 不与常见公开试题明显重复
- [ ] 不因学生记背而得分（考查理解运用而非记忆）
- [ ] 素材对所有学生群体公平（不偏向特定地域/家庭背景）

```
**选项**：
① ……
② ……
③ ……
④ ……

**答案**：①/②/③/④

**详细解析**：
- ①（正确）：……（说明为什么对，对应哪个知识点）
- ②（错误）：……（错误原因，错误类型：……）
- ③（错误）：……（错误原因，错误类型：……）

**考查信息**：
- 核心素养：……
- 对应知识点：……（如"八下第一课 维护宪法权威"）

- 难度：易 / 中 / 难

**素材来源**：（情景材料的原始出处、日期）
```

## 注意事项

1. **干扰项≠装饰项**：每个干扰项必须与题干构成关系，测试的是学生对知识的理解运用而非猜测能力。
2. **禁止否定式提问**："以下说法错误的是"可能因印刷不清导致学生误选，且不符合正向考查理念。
3. **政治性审慎第一条**：涉及党、社会主义制度、民族宗教等内容的选项，确信不对学生政治认同产生负面影响。
4. **情景先行**：无情境不成题——先有情景，后有题干与选项。情景是载体，不是装饰。
5. **一道情境可出多道题**：好的情境天然可以对接多个知识点，无需每题换情景。
