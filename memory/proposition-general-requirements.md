# 初中道德与法治试题命制总要求

> 整合自：proposition-master.md（刘文金命题经验）+ 78篇论文综合分析 + 2022版课程标准

## 一、命题依据与课程标准

### 1.1 根本依据

- 《义务教育道德与法治课程标准（2022年版）》
- 统编教材（人民教育出版社）七至九年级全六册
- 习近平新时代中国特色社会主义思想

### 1.2 五大核心素养

| 核心素养 | 内涵 | 典型考查方向 |
|---------|------|-------------|
| **政治认同** | 拥护党的领导，认同中国特色社会主义，坚定四个自信 | 党建精神、制度优势、中国式现代化、民族团结 |
| **道德修养** | 遵守社会公德、职业道德、家庭美德，践行社会主义核心价值观 | 诚信友善、孝亲敬长、社会责任、奉献精神 |
| **法治观念** | 尊法学法守法用法，理解宪法法律至上，权利义务相统一 | 宪法、民法典、未成年人保护、预防犯罪 |
| **健全人格** | 正确认识自我，健康心理品质，积极生活态度 | 情绪调节、青春期心理、珍爱生命、抗挫能力 |
| **责任意识** | 社会责任感、国家认同、国际视野、担当精神 | 亲社会行为、国家安全、生态文明、人类命运共同体 |

### 1.3 六大知识板块

1. 个人成长（认识自我/情绪调节/珍爱生命/青春成长）
2. 道德品质（诚信/友善/孝亲/责任/奉献/尊重）
3. 法治教育（宪法/民法典/未成年人保护/权利义务/违法与犯罪）
4. 国家制度（人大制度/基本经济制度/国家机构/全过程人民民主）
5. 国情发展（改革开放/共同富裕/生态文明/国家安全/新质生产力）
6. 国际视野（人类命运共同体/中国担当/文明交流互鉴）

## 二、命题目标

以考查学生核心素养形成与发展为目标，实现三个转变：

- 从"解题"到"**解决问题**"（立意转变）
- 从"做题"到"**做事做人**"（目标转变）
- 从知识立意 → 能力立意 → **素养立意**（范式转变）

### 三个减少 + 三个增加

| 减少 | 增加 |
|------|------|
| 裸考知识、机械记忆类试题 | 开放性试题 |
| 封闭性考查方式 | 综合性试题 |
| 单一知识点孤立考查 | 探究性试题 |

🎯 考查重点：思维过程、探究过程、做事过程

## 三、命题原则

### 3.1 四大基本原则

1. **依标命题**：全面落实课程目标、课程内容、学业质量要求
2. **政治方向**：以习近平新时代中国特色社会主义思想为指导，弘扬革命文化，传承中华优秀传统文化
3. **素养导向**：情境创设、任务设置、评分方式有所突破，体现综合性、开放性、应用性、探究性
4. **立德树人**：试题本身就是立德树人的有机组成部分，具有正向价值引领功能

### 3.2 总体要求

**主题优先、能力是关键、知识为载体、素养为导向**

注重整体架构、思维与逻辑统一

## 四、命题规划

### 4.1 双向细目表

每道题须在以下三层面定位：

| 维度 | 内容 |
|------|------|
| **知识点** | 对应六大板块具体知识条目 |
| **核心素养** | 五大核心素养至少覆盖一项 |
| **学科任务层级** | 辨识与判断 / 阐释与论证 / 探究与建构 |

### 4.2 试卷结构参考（成都2025）

| 题型 | 题量 | 分值 | 占比 |
|------|------|------|------|
| 选择题（客观题） | 16题×3分 | 48分 | 48% |
| 分析说明题（主观题） | 4道 | 52分 | 52% |

### 4.3 难度控制

- 容易:中等:难题 = **7:2:1**
- 预设难度系数：**0.65-0.75**
- 难度调节四维度：命题规划（原点）、真实情境（基点）、学科任务（锚点）、课程内容（落点）

## 五、试题命制

### 5.1 试题四要素

| 要素 | 角色 | 核心理念 |
|------|------|---------|
| **立意** | 核心 | 素养导向、价值引领、能力为重、知识为基 |
| **情境** | 载体 | 真实性、典型性、适切性——**无情境不成题** |
| **设问** | 呈现 | 准确简明、指向明确、考查思维过程 |
| **答案** | 归宿 | 分析解释、非抄材料——核心是**把问题说清楚** |

### 5.2 情境材料要求

- 来源：生产生活、社会实际、时政热点
- 真实性：可来自真实事件或基于真实事件的结构化改造
- 典型性：为绝大多数学生熟悉或能够理解
- 适切性：不超出初中毕业生认知水平
- 呈现方式：文字 / 数据示意图 / 原理图 / 结构图 / 数据表格
- 成都本地素材优先
- 专业概念须在材料中用通俗语言解释
- 一份情境应能关联多个知识点（避免孤立考查）

### 5.3 素材来源（权威渠道）

**国家级**：人民网、新华网、教育部官网、中国普法网、最高法/最高检官网、央视网、学习强国

**四川省**：省政府、省教育厅、省高院、省司法厅、省检察院、四川共青团

**成都市**：市政府、市教育局

**中国共产党**：中国共产党新闻网、中组部党建平台

**筛选标准**：近6个月，与课标直接关联，正向价值导向，真实权威

## 七、命题常见逻辑关系

| 类型 | 说明 | 示例陷阱 |
|------|------|---------|
| 充分与必要 | "只要……就……"不等于充分条件 | 必要条件伪装为充分条件 |
| 主观目的与客观效果 | "旨在……" vs "有利于……" | 目的—效果不一致 |
| 原因与结果 | 因果倒置、虚假因果 | "是因为"误用 |
| 应然与实然 | 应然=应该的样子；实然=实际的样子 | 把"应该"说成"已经是" |
| 或然与必然 | "有可能而不一定" vs 必然性 | 把"可能"说成"必然" |

## 八、常见错误与陷阱（通用）

### 8.1 主体错位

- 政府→行政/执法；党→执政；人大→立法；法院→审判；检察院→检察
- 居委会/村委会/政协/社区≠国家机关
- 人大代表才有提案权，公民没有决策权/立法权/审议权
- 监察委员会→监察权（≠检察权）

### 8.2 概念偷换

- 国有经济→主导力量 ≠ 公有制经济→主体地位
- 民族区域自治 ≠ 高度自治（港澳才是）
- 协商民主是特有形式 ≠ 选举民主
- 根本政治制度=人大制度 ≠ 基本政治制度（政党制度/民族区域自治/基层群众自治）
- 宪法是母法 ≠ 宪法是其他法律的总和
- 宪法规定根本性问题 ≠ 一般性问题
- 公民基本权利 ≠ 公民基本政治权利（后者范围更窄）

### 8.3 关系错乱

- 人大产生其他国家机关，其他国家机关对人大负责（不是反过来）
- 国家利益是人民利益的集中体现（不是个人利益是国家利益的集中体现）
- 经济提供物质基础，文化提供精神动力（不能互换）

### 8.4 绝对化表述的逻辑本质

核心认识：绝对化表述的本质是**逻辑错误**，绝对词只是外在语言标记，不能机械排除。

三大逻辑错误类型：
- **以偏概全**：从个别现象推出普遍结论
- **过度推断**：从有限前提推出无限结论
- **偷换模态**：把"可能"说成"必然"，把"应该"说成"已经是"

高频陷阱词：确保、彻底、根除、杜绝、所有、一切、每个、全部、人人、必然、绝对、唯一、"只要……就……""只有……才……"

不可机械排除的例外：
- "青少年应杜绝不良行为"（√，行为要求可以绝对）
- "能/可以/有利于彻底解决"（×，效果不能绝对）
- "消除贫困"（√，政策目标）
- "消除差异/差距/冲突"（×，社会现象）

### 8.5 功利性表述（一定错误）

- "旨在树立良好形象"
- "旨在增加政府职责"
- "为了追求名利回报"

### 8.6 无关项

题干未提及的内容不能选/不能作为答案依据（前后逻辑不相关）

## 九、材料使用规范

### 精简改写原则

- 保留核心事实与数据，删除冗余描述
- 复杂法条转化为通俗语言，不曲解原意
- 不得改变材料的原意和基本价值导向

### 敏感内容规避

- ❌ 未定论的争议案件
- ❌ 负面社会现象的细节描写
- ❌ 对现行政策的批评
- ✅ 涉及负面案例时须补充正面引导，或以警示教育角度呈现
- ✅ 不使用真实未成年人姓名（可用"某中学学生"代称）

## 十一、命题检验通用流程（完整审题）

### 检验清单

**（一）政治性检验**
- [ ] 价值导向是否正确、积极
- [ ] 是否符合习近平新时代中国特色社会主义思想
- [ ] 素材来源是否权威可靠
- [ ] 是否避免敏感、争议过大的案例

**（二）科学性检验**
- [ ] 知识点表述是否准确无误
- [ ] 概念使用是否符合教材规范
- [ ] 无知识性错误（如主体错位、概念混淆）
- [ ] 答案唯一、确定、无争议

**（三）逻辑性检验**
- [ ] 题干与选项/设问与答案之间是否存在必然逻辑关联
- [ ] 干扰项是否有明确错误点（非模糊排除）
- [ ] 无逻辑谬误（绝对化、因果倒置、偷换概念、无关推断）
- [ ] 情境、设问、答案三者是否有机统一

**（四）规范性检验**
- [ ] 字数是否符合要求（选择题题干2-3行/材料题≤300字）
- [ ] 专有名词是否完整表述
- [ ] 选项字数是否相近、排列美观
- [ ] 是否避免否定式提问
- [ ] 是否存在"下列说法正确的是"等不当设问

**（五）公平性检验**
- [ ] 是否与已知公开试题重复
- [ ] 素材是否对所有学生公平（不偏向特定群体）
- [ ] 非记忆测量（不因记背而得分）

### 检验通过标准

五项检验全部通过方可输出试题。存在不合格项的，逐项标注问题并修正后重新检验。

## 十二、配套输出规范

每道试题必须包含：

| 题型 | 必须输出的内容 |
|------|---------------|
| **客观题** | 答案（唯一正确选项）、详细解析（正确为什么对 + 错误选项为什么错）、核心素养、对应教材知识点 |
| **主观题** | 参考答案（完整表述）、分层评分细则（按点/按等级）、典型错误示例、核心素养、对应教材知识点 |
| **判断题** | 每题判断结果、正确说法（改错）、错误类型标注（知识性/逻辑性/价值性）、详细解析、核心素养、知识点 |
| **开放性题目** | 范例方向、说明"言之有理可酌情给分" |
