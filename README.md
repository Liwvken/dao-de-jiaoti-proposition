# 道德与法治命题工具包

> 适用于 **Claude Code** 的初中道德与法治（7-8年级）AI 辅助命题工具包。让 AI 帮你命制选择题、材料分析题、情境探究题和判断题，自带教材知识框架、24 道真题示例库和完整审题检验流程。

---

## 这个工具包能做什么

你只需要说"帮我出几道选择题"或者"来一道关于宪法的材料题"，AI 会自动：

1. 跟你确认年级、考点、难度
2. 问你有无现成素材，没有的话去人民网、新华网等权威网站搜索近 6 个月的时事
3. 按照成都中考规范生成试题（题干、选项、设问、答案）
4. **逐项检验**——政治方向、知识点准确性、逻辑、字数格式——不过关不输出
5. 配上详细解析、核心素养标注和评分标准

## 安装步骤（跟着做就行）

### 前提

你电脑上已经装了 Claude Code。没装的话先去 https://claude.ai/code 下载。

### 第一步：下载工具包

打开终端（Mac 按 `Cmd+空格` 搜"终端"），复制粘贴这行，回车：

```bash
git clone https://github.com/Liwvken/dao-de-jiaoti-proposition.git ~/dao-de-jiaoti-proposition
```

### 第二步：运行安装脚本

```bash
cd ~/dao-de-jiaoti-proposition && bash setup.sh
```

这一步会自动把 4 个技能和教材框架、试题库复制到 Claude Code 能识别的位置。

### 第三步：让 Claude Code 识别新技能

在 Claude Code 里输入：

```
/reload-plugins
```

看到三个新技能出现在技能列表里，就装好了。

## 怎么用

不需要记命令，跟 Claude Code 说话就行。以下是四个技能的用法：

### 1. 命制选择题

**你说**："帮我命制 3 道关于未成年人保护的选择题，八年级，中考模拟难度"

AI 会按流程一步一步来，中间会问你有没有现成素材。你说没有，它就去人民网、中国普法网等搜最新的未成年人保护案例。

### 2. 命制材料题

**你说**："出一道关于国家机构的材料分析题，九年级，12分"

AI 会帮你设计材料、设问（以"结合材料"开头）、分层评分标准。

### 3. 出情景判断题

**你说**："出 4 道关于宪法知识的判断小题，给一个情景"

AI 会编一段真实感的情景，在里面嵌入 3-5 个知识判断点（有对有错），学生要判断正误并改错。

### 4. 存题到题库

**你说**："帮我把这道题存到题库里"然后把题发过来

AI 会自动分析题目考查的知识点，匹配到对应的教材课次，归类到正确目录下。

## 试题库说明

试题库按教材目录组织，就像书架：

```
question-bank/
├── 选择题/
│   ├── 七年级上册/
│   │   ├── 第一课-开启初中生活/
│   │   └── ...
│   └── 八年级下册/
│       └── 第一课-治国安邦的总章程/
├── 材料题/
│   └── ...
```

每道题是一个独立的 Markdown 文件，包含题目、答案、解析、核心素养标注。目前有 24 道题（16 选择 + 8 材料），会持续增加。

### 把你自己出的题加进去

你出一份卷子，可以把整份卷子的题一次发给 Claude Code，说"入库"，它逐道分析知识点、自动归类到对应课次。

## 常见问题

**Q：为什么 AI 问我有没有现成素材？**
A：无情境不成题。你手头有好的案例直接给，没有的话 AI 去权威网站搜。

**Q：生成的题能不能直接用？**
A：AI 已经做过政治性、科学性、逻辑性、规范性、公平性五层检验了，但最终使用时建议你再过一眼。

**Q：我不小心把技能删了怎么办？**
A：重新运行 `bash setup.sh` 就行。

**Q：Mac 怎么打开终端？**
A：按 `Cmd + 空格键`，输入"终端"，回车。
